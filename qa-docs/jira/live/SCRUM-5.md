Try this after you've connected Atlassian Rovo MCP Server to your IDE or set up the Teamwork Graph CLI in your terminal.
This is a sample task to walk you through opening a Jira work item in your local dev tools and letting your agent implement it end to end.
If you’re using Atlassian Rovo MCP:
- In the Development panel on this work item, select your IDE from the dropdown.

- Follow the prompt to open this work item in your editor.

- Ask your agent: Implement this Jira work item. The agent will read the description and make the change.

- Review the diff, commit, and open a pull request from your editor.

- Head back to this work item. Your linked pull request will appear in the agent panel.

If you’re using Teamwork Graph CLI:
- In your terminal, ask your agent: Implement this Jira work item – include the work item URL or ID as context.

- The agent will read the description and make the change.

- Review the diff and merge or close the PR.

- Head back to this work item. Your linked pull request will appear in the agent panel.
